
# 🖼️ AI Image Description

Веб-приложение для автоматического описания изображений
на английском и русском языках с использованием
предобученных нейросетевых моделей Hugging Face.


## 🌐 Онлайн-версия приложения

Приложение развёрнуто в облаке Streamlit Community Cloud
и доступно для использования без локальной установки.

**🚀 [Открыть AI Image Description](https://ai-image-description-elvira.streamlit.app)**

Для работы необходимо загрузить изображение в формате
JPG, JPEG или PNG, выбрать быстрый либо подробный режим
и нажать кнопку «Анализировать изображение».

Результат отображается на английском и русском языках.


## Возможности

- Загрузка изображений JPG, JPEG и PNG.
- Два режима анализа изображений.
- Автоматический перевод описания на русский язык.
- Отображение результатов на двух языках.
- Скачивание описания в формате TXT.
- Современный веб-интерфейс на Streamlit.

## Используемые модели

### 1. BLIP — быстрый режим

Модель: `Salesforce/blip-image-captioning-base`

Создаёт краткое описание основных объектов изображения.

### 2. Florence-2 — подробный режим

Модель: `florence-community/Florence-2-base-ft`

Создаёт развёрнутое описание изображения,
включая объекты, детали и окружающую обстановку.

### 3. OPUS-MT — перевод

Модель: `Helsinki-NLP/opus-mt-en-ru`

Переводит сформированное описание
с английского языка на русский.

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/fakhreeva2005-tech/AI-Image-Description.git
cd AI-Image-Description
```

Создать виртуальное окружение:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить приложение:

```bash
python -m streamlit run app.py
```

После запуска приложение будет доступно
по адресу http://localhost:8501.

При первом анализе изображения модели
автоматически загружаются с Hugging Face.

## Автоматическое тестирование

Установить зависимости для тестирования:

```bash
pip install -r requirements-dev.txt
```

Запустить тесты:

```bash
python -m pytest tests/ -v
```

Тесты проверяют обработку пустого текста
и логику генерации описаний с использованием
имитаций нейросетевых моделей.

## CI — GitHub Actions

В проекте настроен GitHub Actions.

При каждом `push` и `pull_request` в ветку `main`
автоматически выполняются:

1. Подготовка Python 3.11.
2. Установка зависимостей.
3. Запуск тестов pytest.

Конфигурация находится в файле
`.github/workflows/tests.yml`.

## Ограничения

Нейросети могут допускать неточности при распознавании
объектов и переводе текста. Результаты анализа
рекомендуется проверять пользователю.
